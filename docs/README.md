# 🌐 Portfólio Pessoal - David Rocha

Este é o meu portfólio pessoal, desenvolvido como um projeto de estudo para apresentar minhas habilidades e projetos acadêmicos e pessoais. O site foi construído de forma elegante e simplificada, com todas as funcionalidades e estilos contidos em um único arquivo HTML.

👉 Você pode acessar o site publicado aqui:  
🔗 [Acessar Portfólio](https://david-rocha-1775.github.io/portifolio/)

---

## ✨ Destaques do Projeto
- **Design Responsivo:** A interface se adapta perfeitamente a qualquer dispositivo (computadores, tablets e smartphones).  
- **Modo Claro e Escuro:** Alternância de tema com um clique, para uma experiência de visualização confortável em qualquer ambiente.  
- **Seção de Habilidades Interativa:** Ao clicar em uma habilidade, um modal aparece com uma breve descrição de como ela foi adquirida.  
- **Organização de Projetos:** Os projetos estão divididos em categorias para facilitar a navegação e a apresentação.  

---

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e acessível.  
- **Tailwind CSS:** Para estilização e design personalizado.  
- **JavaScript:** Para interatividade e funcionalidades dinâmicas.  
- **Font Awesome:** Ícones sociais e de interface.  
- **GitHub Pages:** Hospedagem e publicação do site.  

---

## 📁 Estrutura do Repositório
- `index.html` – Contém toda a estrutura, estilos e scripts do site em um único arquivo.  
- `README.md` – Este documento.  
- `img/` – Pasta que contém as imagens usadas no site.
