# 🌐 Projeto Site – Curso Técnico  

Esta pasta contém o desenvolvimento de um site completo como parte das atividades do curso técnico em informática/desenvolvimento web. O objetivo é aplicar os conceitos aprendidos em sala, desde a estruturação com HTML até a estilização com CSS, criando uma página funcional, organizada e responsiva.  

## 🧠 Objetivos do Projeto  

- Praticar a criação de um site do zero  
- Aplicar conceitos de **HTML5 semântico** para estruturar o conteúdo  
- Utilizar **CSS3** para estilização e responsividade  
- Desenvolver **layouts organizados** utilizando Flexbox e Grid  
- Incluir **interatividade visual** com transições e animações simples  
- Simular a criação de um site real dentro de um projeto educacional  

## 🛠️ Tecnologias Utilizadas  

- **HTML5**  
- **CSS3**  
- Ferramentas: **VS Code**  

## 📌 Estrutura do Projeto  

O site está organizado em pastas e arquivos que separam as diferentes partes do desenvolvimento:  

- `index.html` → Página inicial do site  
- `/css` → Estilos gerais  
- `/img` → Imagens, ícones e outros recursos  
- Outras páginas e seções poderão ser adicionadas conforme o projeto avança

- Aplicar responsividade para diferentes dispositivos  
- Melhorar o design com animações e efeitos visuais  
- Adicionar novas páginas ou seções, conforme necessário
