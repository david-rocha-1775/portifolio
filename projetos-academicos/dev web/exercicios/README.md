# 📘 Exercícios de HTML e CSS – Curso Técnico  

Esta pasta contém os exercícios realizados durante o curso técnico de informatica. O objetivo é praticar os conceitos fundamentais de **HTML5** e **CSS3**, aplicando-os em pequenas atividades que reforçam a estruturação e a estilização de páginas web.  

## 🧠 Objetivos dos Exercícios  

- Fixar a utilização de **tags HTML5** e boas práticas de semântica  
- Explorar diferentes formas de **estilização com CSS3**  
- Praticar **responsividade** com Flexbox e Grid  
- Criar pequenos exemplos de **layouts e componentes**  
- Desenvolver habilidades para projetos maiores  

## 🛠️ Tecnologias Utilizadas  

- **HTML5**  
- **CSS3**  
- Ferramentas: **VS Code** 

## 📂 Estrutura da Pasta  

Os exercícios estão organizados em subpastas e arquivos, separados por tema ou conteúdo trabalhado em aula, como:  

- Estruturação de páginas em HTML  
- Estilização com CSS básico e avançado  
- Responsividade (Flexbox e Grid)  
- Atividades práticas propostas no curso  

## 🚀 Observação  

Os exercícios são incrementais e novos arquivos serão adicionados conforme o andamento do curso.
